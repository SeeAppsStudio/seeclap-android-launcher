# 开始使用 SeeClap Launcher

SeeClap Launcher 是一款适用于 Android TV 和 Google TV 电视及机顶盒的主屏幕应用，需要 Android 7 或更高版本。主屏幕上的第一张卡片始终是 SeeClap。

如需主页按钮、遥控器快捷键和按需深度清理，建议让助手安装完整版。Downloader 和 USB 使用轻量版。

## 1. 让助手帮你清理电视（推荐）

将电脑和电视连到同一个 Wi-Fi。在电脑上打开 Claude Code 或 Codex，允许它使用终端，然后把下面这句话发给它。

```text
请按照
https://raw.githubusercontent.com/SeeAppsStudio/seeclap-android-launcher/main/skills/seeclap-tv/SKILL.md
中的说明一步步帮我清理电视上的应用缓存，然后问我是否要安装 SeeClap Launcher。
```

现在就可以清理缓存。助手会执行命令，并告诉你什么时候需要用遥控器在电视上确认连接。清理缓存会保留应用和登录状态。如果助手建议停用某个预装应用，由你决定是否停用。

## 2. 只安装启动器，无需 AI

### 使用 Downloader 安装

1. 在电视上打开 Google Play，搜索 Downloader by AFTVnews，安装后打开。
2. **在 Downloader 中输入的代码 — `6812755`**. 在 Downloader 的地址栏输入这里显示的代码，选择 Go，等待 AFTVnews 跳转到官方 APK 文件。如果无法跳转，请在地址栏输入下方的下载直链。
3. 在 Android 8 或更高版本上，只有当系统提示时，才允许 Downloader 安装应用。在 Android 7 上，临时开启“未知来源”。返回 APK 文件，选择“安装”，再选择“打开”。安装后请关闭刚才开启的权限。

### 使用 U 盘安装

APK 是可以在电视上直接安装的文件。

1. [下载 SeeClap Launcher 1.0.1 安装包（APK）](https://github.com/SeeAppsStudio/seeclap-android-launcher/releases/download/v1.0.1/seeclap-launcher-4.apk)。
2. 把文件复制到 U 盘，将 U 盘插入电视，用电视上的文件管理器打开文件。
3. 如果电视提示需要安装权限，请临时允许，安装后再关闭该权限。打开 **SeeClap Launcher**，跟着屏幕上的提示完成设置。
