# SeeClap Launcher 安装指南

在搭载 Android TV 7 或更高版本的电视或电视盒子上，SeeClap Launcher 会显示你收藏的应用以及这些应用分享的节目。选择第一张应用卡片即可打开 SeeClap。如果还没有安装，会出现安装选项。

## 使用电脑和 AI 助手

即使首个 APK 尚未发布，你也可以检查自己的电视并清理缓存。这套工具包借鉴了 [CleanYourTV](https://github.com/Gathin23/cleanyourtv) 的方法。等官方 APK 发布后，你还可以用它来协助安装启动器。

1. 将电视和电脑连接到同一个专用网络。在电脑上准备好可以使用终端的 Claude Code 或 Codex，并安装包含 `adb` 的 Android SDK Platform-Tools。
2. 在电视上打开**设置 › 系统 › 关于**，连续七次按系统版本号（Build）以显示开发者选项。如果电视支持，临时开启无线调试或网络调试。按照提示配对，并在电视上确认是你的电脑正在连接。菜单名称可能因型号而异。
3. 将[完整中文版 AI 工具包的说明](https://github.com/SeeAppsStudio/seeclap-launcher-android-tv/blob/main/kit/PROMPT.zh.md)复制到助手中，再加上你的要求。可以复制下面这段话。

> 请检查我的电视型号，分别测量清理缓存前后的可用空间。保留我的应用数据和登录状态。请勿使用 `pm clear`，它会清除应用数据。停用或卸载任何应用之前，请告诉我是哪个应用，并等我明确选择后再操作。

能腾出多少空间取决于缓存内容，可用空间也可能没有变化。完成后请在电视菜单中关闭调试。如果无法使用 ADB，请按下文的手动方法操作。安装启动器需要官方 APK，首个版本发布后才可下载。

## 安装启动器

1. 打开 SeeClap Launcher 在 GitHub 上的官方项目主页，进入 **Releases**，选择最新版本，再展开 **Assets**。首个版本发布前，这里没有可下载的 APK。Google Play 版已列入计划。
2. 下载 `seeclap-launcher-<code>.apk`，其中 `<code>` 代表版本编号。可以使用电视浏览器下载，也可以在电脑上下载后复制到 U 盘，再用电视上的文件管理器打开。
3. 如果 Android 阻止安装，请打开提示中的设置。Android 8 及更高版本需要为打开文件的那个应用开启**安装未知应用**权限。在 Android 7 上，请在安全设置中临时开启**未知来源**。
4. 返回 APK 文件，确认**安装**，然后关闭刚才开启的权限。从电视的应用列表中打开 **SeeClap Launcher**。

## 首次启动

1. 选择**开始**。按左右方向键预览主题，按 OK 确认。**自动**会跟随电视的主题，也可以选择**浅色**或**深色**。
2. 如果还没有 SeeClap，请选择**安装**或**稍后**。启动器会打开可用的商店（Google Play 或 Fire TV 上的 Amazon 商店）。APK 版也可以从 SeeClap 官网下载应用并验证签名。请在 Android 中确认安装。Google Play 版通过商店安装和更新应用。
3. 除 SeeClap 外，默认布局最多可再选 5 个收藏应用，使用大卡片布局时最多可再选 4 个。选择**继续**即可保存。
4. 如果 Android 提示为主页键选择默认主屏幕应用，请选择 SeeClap Launcher。如果向导显示**打开无障碍**，请阅读服务说明。选择**开**继续，然后在 Android 设置中启用 **SeeClap Launcher – 主页按钮**。选择**取消**可以关闭请求，选择**稍后**可以跳过这一步。
5. 该服务启用后，按一下你要指定的遥控器按键。以后短按此键即可打开 SeeClap。如果原来的应用已安装且启动器能识别它，在**设置 › 遥控器**中开启相应选项后，长按可打开原来的应用。
6. 可按需运行清理，也可选择**继续**，再选择**前往主页**。以后可以在**设置 › 重新运行设置向导**中重新检查这些选择。

## 使用遥控器和应用

- 按左右方向键切换收藏应用，按 OK 打开。向上可进入节目区或播放控件，两者都没有时则进入顶部菜单。向下可进入应用网格。
- 在其他应用的卡片上长按 OK 或按菜单键，可将应用加入收藏、调整收藏顺序或隐藏应用。如果 Android 请求读取电视节目列表的权限，允许后即可看到当前应用分享的节目卡片。

## 释放存储空间

在**设置 › 清理与加速**中，**快速清理**会按应用文件的大小排列。选择要卸载的应用，然后在 Android 中确认。

**全面清理**使用电视的本地调试功能。开始前请检查选项。你可以清理缓存，也可以停用选定的预装应用。在**已停用的应用**中可以重新启用被启动器停用的应用。已清除的缓存数据无法恢复。

## 返回原来的主屏幕

如果启用了无障碍服务，请选择**设置 › 主页按钮 › 暂停**，然后按主页键。如果另一应用是默认主屏幕，还会显示**打开原来的主屏幕**。如果默认主屏幕是 SeeClap Launcher，请在 Android 的默认应用设置中选择电视厂商的主屏幕应用。不同电视的菜单名称可能有所不同。

## 隐私和使用条款

设置保存在电视上，Android 备份可能会包含这些设置。启动器在电视上读取节目列表，也可以通过 HTTPS 下载节目图片并缓存。APK 版还会连接 `downloads.seeapps.studio` 以进行安装和更新。启动器不展示广告，也不收集使用统计信息。无障碍服务会识别按键并检测原来的主屏幕何时打开，无须读取屏幕内容。

许可证允许个人出于非商业目的使用未经修改的软件。你可以分享官方项目链接。再次分发软件需要事先获得 See Apps Studio 的书面许可。SeeClap 始终位于首位。它的卡片不能移动或隐藏，也不能在启动器内移除或卸载 SeeClap。安装 SeeClap 后，在使用启动器期间请保留该应用。
