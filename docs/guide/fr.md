# SeeClap Launcher sur votre TV

SeeClap Launcher rassemble vos applications favorites sur l’accueil de votre Android TV ou Google TV (Android 7 ou plus récent). SeeClap occupe toujours la première tuile.

Nous recommandons l’installation assistée pour obtenir l’édition complète avec le bouton Accueil, le raccourci télécommande et le nettoyage approfondi sur demande. Downloader et la clé USB utilisent l’édition légère.

## 1. Nettoyer la TV avec un assistant (recommandé)

Connectez l’ordinateur et la TV au même Wi-Fi. Sur l’ordinateur, ouvrez Claude Code ou Codex avec accès au terminal. Copiez cette phrase dans la conversation.

```text
Suis les instructions de
https://raw.githubusercontent.com/SeeAppsStudio/seeclap-android-launcher/main/skills/seeclap-tv/SKILL.md
pour me guider sur ma TV, vider les caches de mes applications
et me proposer d’installer SeeClap Launcher.
```

L’assistant s’occupe des commandes et vous indique quoi confirmer sur la TV avec la télécommande. Le nettoyage conserve vos applications et vos comptes. Si l’assistant propose de désactiver une application, vous décidez avant qu’il agisse.

## 2. Installer seulement SeeClap Launcher, sans IA

### Installer avec Downloader

1. Sur la TV, ouvrez Google Play, recherchez « Downloader by AFTVnews », puis installez et ouvrez l’application.
2. **Code à saisir dans Downloader — `6812755`**. Dans le champ d’adresse, saisissez le code affiché sur cette page, puis choisissez « Go ». Attendez qu’AFTVnews vous redirige vers le fichier officiel. Si la redirection se bloque, saisissez l’adresse directe indiquée ci-dessous.
3. Sous Android 8 ou plus récent, autorisez Downloader à installer des applications uniquement si Android vous le demande. Sous Android 7, activez temporairement « Sources inconnues ». Revenez au fichier, choisissez « Installer », puis « Ouvrir ». Retirez ensuite l’autorisation dans les réglages de la TV.

Adresse directe de l’APK · [downloads.seeapps.studio/launcher/tv.apk](https://downloads.seeapps.studio/launcher/tv.apk)

[Installer SeeClap Launcher sur Android TV et Google TV](https://seeclap.com/fr/android-launcher/tv/)

### Avec une clé USB

Le fichier d’installation est prêt à utiliser. Vous n’avez rien à compiler.

1. [Téléchargez SeeClap Launcher 1.0.1 pour votre TV (APK)](https://github.com/SeeAppsStudio/seeclap-android-launcher/releases/download/v1.0.1/seeclap-launcher-4.apk).
2. Copiez-le sur une clé USB. Branchez-la sur la TV et ouvrez le fichier avec le gestionnaire de fichiers.
3. Si Android le demande, autorisez l’installation, puis retirez cette autorisation après l’installation. Ouvrez **SeeClap Launcher** et suivez les étapes à l’écran.
