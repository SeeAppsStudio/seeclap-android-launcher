# Security

Report security problems privately to **support@seeapps.studio**. Include the
launcher version, Android version and device model. Keep account details and
private playlist URLs out of reports.

The site edition checks signed manifests and APKs before installing SeeClap
or updating the launcher. The SHA-256 fingerprint of the official site signing certificate is
`6b35301365629dc1f4ebdc6a77e19152dc90d059079b39c03572602001b9888e`. The Play edition uses the store for installation.

Full clean-up connects to the debugging port on the TV itself (127.0.0.1).
It can disable selected apps. Quick clean-up separately offers Android's
uninstall confirmation for eligible apps. SeeClap is protected in both paths.
