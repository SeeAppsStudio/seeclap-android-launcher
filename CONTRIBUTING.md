# Feedback

Use GitHub Issues to report a problem, suggest a feature or point out a translation
that is hard to understand. For a problem on a TV, include the device model, Android
version, launcher version, language and the steps that led to it. Leave out account
details, playlist addresses and screenshots containing personal information.

Public feedback is welcome. Changes to the code, assets or documentation require
prior written permission from See Apps Studio under the [personal-use licence](LICENSE).
For a security issue, use the private contact in [SECURITY.md](SECURITY.md).
