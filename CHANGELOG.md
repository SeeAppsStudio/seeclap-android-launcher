# Changelog

## 1.0.2 · Complete edition

- Install the complete signed APK with ADB from a computer. The optional Home-button service and remote shortcut are available in this edition.
- The light APK remains the Downloader and USB edition. The two editions check separate update channels.

## 1.0.1

- The downloadable APK uses Android’s default Home setting and omits the accessibility service. Open it from your apps if the TV does not offer a Home app choice.

- Prefer SeeClap’s direct program feed when available. Fall back to Android TV recommendations regardless of the installed SeeClap version.

## 1.0.0

- SeeClap stays in the first tile. Choose up to five other favorites, or use the larger five-tile layout.
- Browse compatible apps' Android TV recommendations and SeeClap's shared programs with the remote.
- Choose a light or dark appearance during setup, or have the launcher follow the TV automatically.
- Set up Home and a shortcut button on supported remotes. Review optional TV clean-up actions before applying them.
- The site edition can install SeeClap and check for signed updates. The Play edition opens the store.
- The interface and installation guides are available in twelve languages.
- The personal-use licence permits using the unmodified launcher on your own devices.
