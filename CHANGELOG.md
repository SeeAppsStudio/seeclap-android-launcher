# Changelog

## 1.0.0 — in preparation

- SeeClap stays in the first tile. Choose up to five other favorites, or use the larger five-tile layout.
- Browse compatible apps' Android TV recommendations and SeeClap's shared programs with the remote.
- Choose an automatic, light or dark theme during setup, with a matching ambient background.
- Set up Home and a shortcut button on supported remotes. Review optional TV clean-up actions before applying them.
- The site edition can install SeeClap and check for signed updates. The Play edition opens the store.
- The interface and installation guides are available in twelve languages.
- The personal-use licence permits using the unmodified launcher on your own devices.
