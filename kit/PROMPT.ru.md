# Как освободить место на телевизоре с помощью Claude Code или Codex

Подключите компьютер к той же частной сети, что и ваш телевизор с Android TV или Google TV. Запустите Claude Code или Codex с доступом к терминалу и установите `adb` из [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools). Если хотите установить ещё и лаунчер, понадобится `apksigner` из [Android SDK Build-Tools](https://developer.android.com/tools/apksigner).

На телевизоре откройте Настройки › Система › Об устройстве. Если параметры разработчика скрыты, семь раз нажмите на номер сборки. Включите беспроводную отладку или отладку по USB с подходящим кабелем для передачи данных. Подтвердите подключение пультом.

Укажите модель и язык в первой строке и вставьте весь блок в чат с помощником.

```text
Мой телевизор — [марка и модель]. Отвечай на [русском языке]. Помоги очистить кеш. На
установку лаунчера и отключение приложений спроси отдельное разрешение.

1. Для Wi-Fi возьми с экрана телевизора адрес и порт сопряжения для adb pair. Код я введу на
компьютере сам. При необходимости используй затем порт подключения для adb connect. При
подключении по USB дождись, пока я разрешу доступ на телевизоре. Найди мой телевизор в списке
и подставляй его идентификатор вместо SERIAL в каждой команде. Если есть сомнения, спроси
меня.

adb pair IP:PAIR_PORT
adb connect IP:CONNECT_PORT
adb devices -l

2. Сохрани в папке с датой на моём компьютере модель, версию Android, номер активного
пользователя и название приложения главного экрана. Уточни у меня, тот ли это телевизор.

adb -s SERIAL shell getprop ro.product.model
adb -s SERIAL shell getprop ro.build.version.release
adb -s SERIAL shell am get-current-user
adb -s SERIAL shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME

3. Измерь свободное место в /data, попроси Android очистить кеш и повтори замер. Сообщи
разницу, даже если она нулевая. Со временем кеш может вырасти снова. Не используй pm clear:
эта команда стирает и данные приложения.

adb -s SERIAL shell df -k /data
adb -s SERIAL shell pm trim-caches 999999999999
adb -s SERIAL shell df -k /data

4. Только по моей просьбе скачай на компьютер официальную полную версию по ссылке ниже. Проверь, что имя пакета — studio.seeapps.home.

https://downloads.seeapps.studio/launcher/tv-full.apk

apksigner verify --print-certs APP.apk

6b35301365629dc1f4ebdc6a77e19152dc90d059079b39c03572602001b9888e

Выполни adb -s SERIAL install -r APP.apk только при действительной подписи и совпадении
сертификата. Иначе пропусти установку.

5. Если я хочу отключить приложения, используй списки для моделей из проекта CleanYourTV
автора Gathin23. Убедись, что модель точно совпадает, и объясни назначение каждого пакета.
Пропусти всё, в чём не уверен.

https://github.com/Gathin23/cleanyourtv

Запиши профиль и исходное состояние каждого включённого пакета. Получи моё согласие на каждое
приложение, затем используй pm disable-user --user ID ПАКЕТ через adb -s SERIAL shell.
Сохрани полную команду восстановления: pm enable --user ID ПАКЕТ, если оно было явно
включено, или pm default-state --user ID ПАКЕТ для состояния по умолчанию. Заранее проверь
доступность команды восстановления.

Никогда не отключай и не удаляй SeeClap, его лаунчер, главный экран производителя и важные
службы: сеть, настройки, клавиатуру, Cast и обновления. Оставь SeeClap первой плиткой.
Защищай эти пакеты:

com.seeappsstudio.seeclap / com.codingbyjerez.seeclap / studio.seeapps.home

6. В полной версии я сам могу включить дополнительную службу кнопки «Домой» в специальных возможностях телевизора и выбрать горячую клавишу в настройках пульта лаунчера.
Позволь мне выбрать главный экран в настройках Android. Если такого пункта нет, покажи, как открыть SeeClap Launcher из списка приложений телевизора. Сообщи о блокировке установки, дай журнал и инструкции по отмене изменений, затем отключи ADB.
```
